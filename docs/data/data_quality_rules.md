# 数据质量检查与后续处理规则

## 本阶段检查内容

- 数据规模：文件大小、行数、列数、用户数、商品数和类目数。
- 字段完整性：五个关键字段的缺失数量及存在缺失的行数。
- 非法值：非正整数或超出 int64 的 ID、非 `1/2/3/4` 的行为编码、非 `YYYY-MM-DD HH` 的时间。
- 完全重复：五个字段完全相同的记录单独统计重复组数、涉及记录数和多余记录数。
- 疑似重复：`user_id + item_id + behavior_type + time` 相同的记录只统计，不删除。

## 后续处理规则

- 原始 CSV 不直接修改。
- 缺失关键字段、非法取值和异常时间记录由后续清洗任务决定删除或标记，本阶段不处理。
- 完全重复是否删除必须结合数据来源说明决定，本阶段只统计。
- 疑似重复可能是同一小时内的真实重复行为，不直接删除。
- `user_id`、`item_id`、`item_category` 是标识符，不使用 IQR 或 3σ 判断异常。

## 本阶段输出

运行 `python scripts/check_data_quality.py` 输出 `reports/stage1/data_quality_report.json`。报告只包含检查统计和处理决策记录，不输出清洗后的数据。
