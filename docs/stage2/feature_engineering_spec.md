# 阶段二特征工程口径

## 范围

本阶段只基于 `data/processed/user_behavior_clean.parquet` 生成四张基础统计中间表：用户、商品、类目和时间。中间表是后续特征构造的输入，不是最终特征表，不直接用于模型训练。

本阶段不生成标签、样本划分文件、用户—商品表、最终特征宽表，不执行采样、模型训练或模型评估。

## 时间窗口

| `dataset_split` | 历史统计起点 | 历史统计终点 | 标签日（本阶段排除） |
| --- | --- | --- | --- |
| `train` | 2025-11-18 | 2025-12-07 | 2025-12-08 |
| `validation` | 2025-12-09 | 2025-12-14 | 2025-12-15 |
| `test` | 2025-12-16 | 2025-12-17 | 2025-12-18 |

起止日期均为闭区间。每一行中间表都写入 `history_start`、`history_end` 和 `label_date`，该行全部统计字段只使用对应历史闭区间内的事件。

## 防止未来信息泄露

- 标签日事件不进入任何中间表统计。
- 标签日之后的事件不进入对应中间表统计。
- 三个历史窗口分别聚合，不跨窗口累计。
- `first_event_time` 和 `last_event_time` 只能落在该行的历史窗口内。
- 本阶段不读取或构造标签，因此中间表中不存在 `label` 字段。

## 字段与粒度

- 用户中间表：每个 `dataset_split + user_id` 一行。
- 商品中间表：每个 `dataset_split + item_id` 一行；`item_id` 在窗口内必须只对应一个 `category_id`。
- 类目中间表：每个 `dataset_split + category_id` 一行。
- 时间中间表：每个 `dataset_split + behavior_date + behavior_hour` 一行，只输出实际出现的日期—小时组合。
- 行为编码：`1=pv`、`2=fav`、`3=cart`、`4=buy`。
- 所有计数均为对应历史窗口内的原始事件计数，不跨标签日补数。

## 转化率统一口径

转化率只在本文件定义，当前四张中间表只保存分子和分母计数，不计算或输出转化率。

| 名称 | 后续计算公式 | 约束 |
| --- | --- | --- |
| 浏览购买比 | `buy_count / pv_count` | 分子、分母必须来自同一粒度、同一 `dataset_split` 和同一历史窗口 |
| 收藏购买比 | `buy_count / fav_count` | 同上 |
| 加购购买比 | `buy_count / cart_count` | 同上 |

分母为 0 时结果定义为缺失值，不记为 0；不进行平滑。上述比率是历史行为次数比，不表示严格按时间顺序发生的用户转化概率。
