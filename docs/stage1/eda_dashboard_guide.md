# Stage 1 EDA Dashboard Guide

## 1. Overview

The Stage 1 EDA dashboard is the visualization layer for Issue #5.

It consumes the aggregate outputs generated by the Stage 1 EDA pipeline.
It does not reimplement the full EDA logic or process the complete clean dataset.

Dashboard entry point: dashboards/eda/app.py

EDA data loader: dashboards/eda/data_loader.py

---

## 2. Environment

Recommended Python version: `3.11.9`.

Install project dependencies from the repository root:

`python -m pip install -r .\requirements.txt`

The dashboard uses the following main packages:

- `pandas`
- `pyarrow`
- `streamlit`
- `plotly`

---

## 3. EDA Output Prerequisite

The dashboard depends on Stage 1 EDA aggregate outputs stored in:

`data/interim/`

These outputs are generated by:

`python .\src\data\EDA_analysis.py`

The EDA pipeline uses the cleaned Parquet dataset:

`data/processed/user_behavior_clean.parquet`

The current formal clean dataset contains 12,256,906 rows.

The dashboard must not recompute full-data EDA during normal startup or interaction.

---

## 4. Required EDA Outputs

The dashboard directly loads these lightweight aggregate outputs:

- `behavior_distribution.csv`
- `user_purchase_summary.csv`
- `top_10_item.csv`
- `category_statistics.csv`
- `top_10_category.csv`
- `daily_behavior.csv`
- `hourly_behavior.csv`
- `descriptive_funnel.csv`

`item_statistics.csv` is also validated as an upstream EDA output, but it is intentionally not loaded during normal dashboard startup because it contains millions of rows.

The Top Items visualization uses `top_10_item.csv` instead.

---

## 5. Starting the Dashboard

From the repository root, run:

`streamlit run .\dashboards\eda\app.py`

Streamlit will start a local development server and open the dashboard in a browser.

The default local address is typically `http://localhost:8501`.

---

## 6. Dashboard Structure

The Stage 1 EDA dashboard contains the following sections:

- Overview
- Behavior Mix
- User Insights
- Top Items
- Top Categories
- Daily Trend
- Hourly Trend
- Conversion Funnel

The left navigation panel provides direct access to each section.

---

## 7. Dashboard Content

### Overview

Displays the main Stage 1 summary metrics:

- Total Behaviors
- Purchase Behaviors
- Purchase Users

### Behavior Mix

Displays the distribution of PV, FAV, CART, and BUY behaviors.

### User Insights

Displays the following purchase-based user segments:

- No Purchase
- Single Purchase
- Repeat Purchase

### Top Items

Displays the Top 10 items ranked by purchase count using `top_10_item.csv`.

### Top Categories

Displays the Top 10 categories ranked by purchase count using `top_10_category.csv`.

### Daily Trend

Displays daily PV, FAV, CART, and BUY behavior trends.

The behavior focus selector supports:

- All Behaviors
- PV
- FAV
- CART
- BUY

Selecting one behavior automatically rescales the Y axis so lower-volume trends can be inspected clearly.

### Hourly Trend

Displays behavior distribution across all 24 hours from 0 through 23.

It provides the same behavior focus selector as the Daily Trend chart.

### Conversion Funnel

Displays the descriptive behavior funnel for PV, Favorite, Cart, and Purchase.

The percentages are calculated relative to PV.

These values are descriptive ratios and must not be interpreted as a strict sequential user conversion path.

---

## 8. Performance Design

The dashboard follows these performance principles:

1. Read Stage 1 aggregate outputs instead of recomputing the complete EDA.
2. Cache loaded dashboard data with Streamlit.
3. Prefer Top-N aggregate outputs for visualization.
4. Do not load the full 12,256,906-row clean dataset during normal dashboard use.
5. Do not load the multi-million-row `item_statistics.csv` during normal dashboard startup.

The dashboard therefore uses lightweight Issue #4 outputs as its primary visualization data source.

---

## 9. Common Errors

### Missing EDA output files

If the dashboard reports missing EDA output files, regenerate the Stage 1 EDA outputs:

`python .\src\data\EDA_analysis.py`

Then restart the dashboard.

### Streamlit command not found

Install project dependencies:

`python -m pip install -r .\requirements.txt`

Then start the dashboard again.

### Dashboard still shows an older version

Stop the running Streamlit process with `Ctrl+C` and restart it:

`streamlit run .\dashboards\eda\app.py`

### Trend lines appear compressed

PV volume is substantially larger than FAV, CART, and BUY.

Use the behavior focus selector above the Daily Trend or Hourly Trend chart to inspect one behavior independently.

---

## 10. Development Validation

Check dashboard Python syntax before committing changes:

`python -m py_compile .\dashboards\eda\data_loader.py .\dashboards\eda\app.py`

Run the full project test suite before final delivery:

`python -m pytest`

Real datasets, large CSV or Parquet files, and large intermediate outputs must not be committed to GitHub.
